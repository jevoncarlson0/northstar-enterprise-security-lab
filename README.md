# Northstar Technologies — Enterprise Security Lab

## Project Overview

Northstar Technologies is a fictional 50-employee company created as a hands-on cybersecurity learning environment.

The purpose of this project is to design, build, secure, and monitor a simulated business IT environment while developing practical skills in networking, Linux, cybersecurity, identity and access management (IAM), cloud security, vulnerability management, security monitoring, and incident response.

This environment will grow as I learn new technologies and security concepts.
